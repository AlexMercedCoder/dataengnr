# DataEngnr

Source for [dataengnr.com](https://dataengnr.com), a data engineering knowledge base by Alex Merced. Built with Astro; term pages live in `src/content/terms/`.

## Commands

| Command | Action |
| :-- | :-- |
| `npm install` | Install dependencies |
| `npm run dev` | Local dev server at `localhost:4321` |
| `npm run build` | Build to `./dist/` and index it with Pagefind |
| `npm run dates` | Refresh `src/data/git-dates.json` from full git history |

## Network files

`network/` is generated by `alexmercedcom/scripts/build-network-shared.mjs`. Do not edit it by hand. `BaseLayout.astro` reads `network-head.html` (GA4 and the Person JSON-LD) and `network.json` (footer groups, CTA strip, `twitter:site`) at build time.

## Dates

`dateModified` in JSON-LD and `<lastmod>` in the sitemap come from git (`src/lib/git-dates.mjs`). With full history the build reads git directly. On a shallow clone it falls back to `src/data/git-dates.json`, so run `npm run dates` and commit the result after content changes.
